# LifeRPG Mobile

Мобильный PWA-прототип LifeRPG: адаптивный интерфейс, квесты, привычки, XP и фокус-таймер.

## Открыть приложение

После успешной публикации GitHub Pages адрес приложения:
https://denovseicev-png.github.io/liferpg-mobile/

Если страница пока не открывается, проверь запуск workflow во вкладке **Actions** репозитория и дождись успешного завершения публикации.

## Установка на Android

1. Открой ссылку выше в Chrome на телефоне.
2. Открой меню ⋮.
3. Выбери **«Установить приложение»** или **«Добавить на главный экран»**.
4. Запусти LifeRPG с появившейся иконки.

Для офлайн-запуска сначала открой приложение при подключении к интернету, чтобы браузер смог сохранить оболочку.

## Самопроверка и публикация

Файл `.github/workflows/pages.yml` автоматически проверяет структуру файлов, JSON-манифест, ссылки на ресурсы и настройки PWA. Если проверки проходят, workflow публикует статические файлы через GitHub Pages. Запустить повторно можно во вкладке **Actions** через **Run workflow**, если GitHub предлагает эту кнопку.

## Возможности мобильной версии

- Квесты, повторяющиеся расписания, привычки, цели и этапы.
- Глобальный поиск по квестам, привычкам, целям, заметкам, карточкам и наградам.
- Учёба: оценки, пробники, темы, карточки интервального повторения и журнал учебных сессий.
- XP, уровни, достижения, журнал и экспорт CSV.
- План дня, чекин энергии/настроения, дневник, заметки и недельный обзор.
- Календарь активности, шаблоны квестов, мини-задачи с XP и монетами, экран атрибутов героя и древо навыков, классы персонажа, заморозки серии и отложенные бонусы.
- Отдельный центр фокуса с тремя настраиваемыми режимами, циклом фокус/отдых и паузой.
- Награда XP за каждые полные 10 минут активного фокуса с выбором суммы и атрибута; лимитные награды переходят в отложенные бонусы.
- Игровой банк, магазин наград и кредиты.
- Испытания недели, статистика атрибутов и настраиваемые дневные/недельные лимиты XP.
- Резервная копия JSON, восстановление и работа офлайн после первого открытия.

## Важные ограничения

- Это отдельный мобильный прототип, а не полный перенос настольного LifeRPG на Python.
- Данные хранятся локально в браузере устройства; синхронизации с настольным приложением и `rpg.db` нет.
- Очистка данных браузера может удалить локальный прогресс. Пока не считай прототип единственным местом хранения важных данных.
- Репозиторий публичный: любой может просматривать и копировать исходный код. Не добавляй пароли, ключи и личные секреты.

### Раздел «Фокус»

- Три независимых профиля: Короткий (25/5), Глубокий (50/10), Длинный (90/15 минут) — названия и длительности можно менять.
- Отдельно настраиваются XP за каждые 10 минут и атрибут награды, включая «Разум».
- XP выдаётся сразу за каждый полный десятиминутный блок накопленного активного фокуса. Отдых не учитывается, остаток меньше 10 минут переносится между циклами.
- При исчерпании XP-лимита награда сохраняется в «Отложенных бонусах» с выбранным атрибутом.
- Пауза и смена режима не обнуляют уже накопленное время или выданные блоки. Сброс не отменяет начисленный XP и спрашивает подтверждение, если остался неполный блок.
- При сворачивании PWA таймер ставится на паузу; после перезапуска приложения он не продолжает отсчёт автоматически.

Настройки и состояние фокуса хранятся локально в данных PWA. Старое значение длительности фокуса переносится в первый профиль при миграции.
- Если сохранение тика таймера не удалось (например, хранилище переполнено), последний тик и связанная с ним награда откатываются, а таймер останавливается на последнем сохранённом состоянии.
