# LifeRPG Mobile

Это мобильный PWA-прототип с адаптивным интерфейсом, квестами, привычками и фокус-таймером.

## Важно
- Это отдельный прототип, не полный перенос настольного LifeRPG на Python.
- Данные сохраняются локально в браузере устройства.
- Синхронизации с настольным приложением и `rpg.db` нет.
- Не вводи секретные данные: репозиторий и способ публикации могут быть доступны другим людям.

## Публикация
Для бесплатного GitHub Pages на личном аккаунте, как правило, нужен публичный репозиторий. Если репозиторий приватный, не меняй его видимость ради публикации без решения о приватности. Можно оставить репозиторий закрытым и выбрать другой хостинг или подходящий тариф.

## Установка на Android
Когда сайт опубликован по HTTPS, открой его в Chrome на телефоне и выбери меню ⋮ → «Добавить на главный экран» или «Установить приложение». Доступность установки зависит от браузера и настроек публикации.
